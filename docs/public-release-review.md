# GitHub 공개 전 재검토 — 2026-09-10

**공개 결정: 사용자가 팀원 동의를 확인하고 Public 전환을 명시적으로 요청했습니다.** 보안 코드는 PR #49로 반영했고, 이후 사용자의 명시적 승인을 받아 28개 원격 브랜치의 이력 교체까지 완료했습니다. 과거 GitHub 객체의 잔존과 자산 권리의 미확인 상태를 설명한 뒤 사용자의 공개 요청을 받았습니다. 라이선스 고지를 원격에 반영한 후 공개 설정을 변경합니다. 사용자가 이미지 노출은 문제없다고 확인했으므로 사진 노출 우려는 보류 사유에서 제외합니다. 비밀값과 사용자 미디어는 이 문서에 기록하지 않습니다.

## 완료한 코드 정리

- DB 접속정보를 `backend/app/core/config.py`에서 환경변수로만 읽도록 통합했습니다. 비밀번호가 들어 있는 기본 접속 문자열을 제거했습니다.
- JWT 기본키를 제거하고 키 누락 또는 짧은 키를 거부합니다. 로컬에서 사용하던 약한 키를 교체했습니다. 서버 재시작 후 기존 앱 로그인은 다시 해야 합니다.
- 로그인 화면에서 토큰·서버 응답·사용자 정보를 출력하던 로그를 제거했습니다.
- Alembic에 자격증명을 직접 기록하지 않고 중앙 설정을 전달합니다. URL 인코딩된 비밀번호가 `%` 보간 오류를 일으키지 않도록 URL을 직접 사용합니다.
- 환경파일 예시와 비밀 설정 검사 테스트를 추가했습니다.
- 업로드 사진·영상, 모델 가중치 3개, macOS 시스템 파일을 Git 추적에서 제외했습니다. 로컬 원본은 보존했습니다. 업로드 ignore 경로도 수정했습니다.

## 공개 결정 시 남아 있는 확인 사항

1. 원격 이력 교체는 완료했지만 GitHub의 과거 PR 참조와 캐시에는 이력 재작성 후에도 예전 파일이 남을 수 있습니다. 추가 제거를 원한다면 GitHub Support 처리가 필요하지만 문의 자체가 공개 전환의 필수 조건은 아닙니다. 사용한 비밀번호·키는 교체했으며 이미지 노출은 사용자가 문제없다고 확인했습니다. 원격 브랜치의 정리와 서버에서 과거 객체를 완전히 제거하는 것은 다릅니다.
2. 팀 코드 공개 동의는 사용자가 받았다고 확인했습니다. 모델·학습 데이터·일부 앱 자산의 재배포 권한은 별도 미확인 상태입니다. 모델 가중치는 제외했지만 Ultralytics 관련 서비스 코드의 라이선스 판단까지 끝났다는 뜻은 아닙니다.
3. 현재 앱 자산 130개 중 아이콘 15개와 Expo 기본 이미지 7개는 공식 배포본과 대조하고 `THIRD_PARTY_NOTICES.md`에 라이선스 고지를 추가했습니다. 나머지 108개는 재배포 권한 미확인 상태로 기록하며, 출처·이용 조건 확인이나 허가된 대체 자산으로의 교체가 후속 사항으로 남습니다. 수거함 데이터의 공식 배포 페이지는 찾았지만 원본 파일 대조와 추가 좌표의 출처는 아직 미확인입니다. 파일별 상태는 `docs/asset-rights-inventory.csv`, 근거는 `docs/asset-verification-evidence.json`, 설명은 `docs/assets-publication.md`를 참고하세요.
4. 과거 DB 자격증명을 다른 DB나 서비스에서도 재사용했다면 해당 서비스도 변경해야 합니다. 이번에 확인한 것은 Mac 로컬 DB뿐입니다.

이번 이력 검사에는 2MB 미만 UTF-8 파일 패턴 검사와 민감 경로 확인을 사용합니다. 바이너리 전체 내용, 모든 외부 첨부 대상 및 비밀값의 실제 유효성을 전수 확인하지 않으므로 비밀값 부재를 보증하지 않습니다.

GitHub Support 로그인과 2단계 인증은 완료했으나 사용자가 Public 전환을 요청하여 지원 문의 없이 진행합니다. 지원 요청은 전송하지 않았습니다. PR 47개, 최초 변경 커밋 2개, 과거 파일 객체와 이슈 #23 첨부 위치를 포함한 제출용 문서를 Git에서 제외된 로컬 백업 폴더에 준비했습니다. 공개 요청 직전 확인에서는 저장소가 PRIVATE였으며 관리 권한을 확인했습니다. 실제 공개 여부는 GitHub 저장소 설정을 기준으로 합니다.
