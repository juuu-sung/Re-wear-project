# 공개 자산 확인표

사용자는 팀원 공개 동의를 확인하고 저장소 Public 전환을 요청했습니다. 아래 미확인 항목을 확인 완료로 바꾸지는 않습니다. 코드가 공개 가능한지와 제3자 자산을 재배포 가능한지는 별도 확인이 필요합니다.

| 대상 | 현재 조치 | 남은 증빙 |
| --- | --- | --- |
| backend/uploads의 개인 사진·채팅 미디어 | Git 추적과 공개 대상 이력에서 제외, 로컬 원본 보존 | 사용자가 이미지 노출은 문제없다고 확인; 노출 우려로 추가 삭제를 요구하지 않음 |
| best.pt, best_ml.pt, best_multitask.pt | Git 추적과 공개 대상 이력에서 제외, 로컬 실행용 파일 보존 | 학습 데이터 출처·이용 조건, 모델 배포 권한 |
| assets/icons SVG 15개 | Ionicons 5.5.4 공식 배포본의 도형과 일치, MIT 고지 추가 | 색상·스타일 변경 이외 도형 일치 확인 완료 |
| assets/images 기본 이미지 7개 | Expo 기본 템플릿 57.0.23과 SHA-256 일치, 배포본 LICENSE 고지 추가 | 로고의 상표권 사용 허가까지 의미하지 않음 |
| 나머지 이미지·게임 Lottie·배경·세탁기호 | 출처 미확인 기록 유지 | 원본 링크, 작성자, 라이선스, 필요한 저작자 표시 |
| assets/data CSV·브랜드 자료 | 재배포 조건 미확인 기록 유지 | 데이터 제공처 링크와 이용 조건 |
| README 배너 및 앱 화면 자료 | 제작 과정·표시 내용 확인 필요 | 제작자 동의 및 포함 이미지 권한 |
| 팀 코드 | 공개 라이선스 임의 추가하지 않음 | 팀원 공개 동의는 사용자 확인 완료; 제3자 코드와 호환되는 라이선스 선택은 별도 |
| 이슈 #23 첨부 이미지 | 본문에서 링크 제거 완료 (첨부 원본 삭제는 미확인) | 사용자가 이미지 노출은 문제없다고 확인; 원본 삭제 완료를 의미하지 않음 |

모델을 받는 사람은 허가된 경로로 파일을 받아 기존 경로에 배치해야 합니다. 저장소만 새로 복제한 환경에서는 해당 모델 파일이 없으므로 모델 기반 API 실행 전에 별도 준비가 필요합니다.

Ultralytics 모델을 사용하는 서비스 코드의 라이선스 의무는 가중치를 제외하는 것만으로 해결됐다고 판단하지 않습니다. [공급자 안내](https://www.ultralytics.com/license)를 확인하고 적용 조건을 결정해야 합니다. AI Hub 데이터는 사용한 정확한 데이터셋의 이용 조건을 확인해야 합니다.

## 2026-09-10 추가 확인

현재 추적 자산 130개 중 22개를 공식 배포본과 대조하고 `THIRD_PARTY_NOTICES.md`에 라이선스 원문을 보존했습니다. 남은 108개는 재배포 확인이 끝나지 않았습니다. 파일별 상태는 `asset-rights-inventory.csv`, 파일 해시와 대조 방법은 `asset-verification-evidence.json`에 기록했습니다. 이 숫자는 현재 트리의 자산 목록이며 모든 과거 자산이나 의존성의 권한을 포괄하지 않습니다.

- Ionicons: [공식 MIT 라이선스](https://github.com/ionic-team/ionicons/blob/main/LICENSE). 공식 npm 배포본 5.5.4의 SVG를 비교했습니다. 일부 색상·스타일 변경은 있으나 도형과 나머지 요소 속성은 일치합니다.
- Expo: [공식 템플릿](https://github.com/expo/expo/tree/main/templates/expo-template-default). `expo-template-default@57.0.23`에서 이미지 7개가 바이트 단위로 일치합니다. package.json에는 0BSD, 동봉 LICENSE에는 MIT가 기재되어 있으므로 MIT 저작권 고지까지 보존했습니다.
- 구로구 CSV: 로컬 기준일 2023-03-31과 일치하는 [공식 배포 페이지](https://data.seoul.go.kr/dataList/OA-21855/F/1/datasetView.do)는 이용허락범위 제한 없음으로 표시합니다. 현재 파일 657행의 원본 대조와 추가 latitude/longitude의 생성·제공 출처는 아직 확인되지 않았습니다.
- 양천구 CSV: 로컬 기준일 2023-04-20과 일치하는 [공식 배포 페이지](https://data.seoul.go.kr/dataList/OA-22070/F/1/datasetView.do)는 공공누리 1유형(출처표시)을 명시합니다. 현재 파일 731행의 원본 대조와 추가 latitude/longitude의 출처가 확인되기 전에는 파일 전체를 승인하지 않습니다.
- `assets/game/peas.json`에는 작성자 `Itay Alon`, 설명 `Peas Playground`가 기록되어 있지만 원본 다운로드 페이지·라이선스는 확인하지 못했습니다. Lottie 제작도구 이름만으로 이용 허가를 추정하지 않습니다.

사용자 확인이 필요한 자료는 게임·세탁기호·나머지 이미지의 다운로드 출처, 좌표 생성 서비스, 정확한 AI Hub 데이터셋입니다. 팀원 코드 공개 동의는 사용자가 확인했습니다. 앱 기능과 자산 원본 파일은 이번 확인에서 변경하지 않았습니다.

## 사용자 판단 반영

사용자가 “이미지는 상관없어”라고 확인했습니다. 개인 사진·첨부 이미지의 노출 우려는 공개 보류 사유에서 제외합니다. 이는 외부 자산의 출처·라이선스 증빙이 새로 확인됐다는 뜻은 아니므로 파일별 재배포 확인 상태는 그대로 기록합니다. GitHub Support 문의 자체는 public 전환의 필수 조건이 아닙니다.

이후 사용자가 팀원에게 공개 동의를 받았다고 확인하고 Public 전환을 명시적으로 요청했습니다. 이 결정은 미확인 제3자 라이선스에 대한 검증 완료를 의미하지 않습니다.
