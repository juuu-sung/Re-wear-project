## 이번 개편의 기준

1. **앱을 먼저 설명합니다.** 목적과 실제 화면을 개발 설정보다 앞에 둡니다.
2. **기능을 사용 흐름으로 묶습니다.** 옷을 알아보고, 관리하고, 순환하는 과정을 보여줍니다.
3. **기술에는 역할과 근거를 붙입니다.** 추론·알림·채팅 구현을 코드로 연결합니다.
4. **실행 정보는 별도 문서에서 보존합니다.** 의존성 누락과 DB 보완 사항까지 개발 가이드에 남깁니다.
5. **확인한 자료만 사용합니다.** 화면은 사용자 제공 PDF, 기능·기술은 저장소 구현을 근거로 작성합니다. 다른 앱의 이미지·브랜딩·성과 수치는 Re:wear 소개에 가져오지 않습니다.

팀원의 개발 분야, 앱스토어 배포 링크, 성능 수치, 도입 효과는 확인된 자료가 없어 추가하지 않았습니다.
